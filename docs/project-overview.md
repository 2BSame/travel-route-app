# 여행 루트 추천 앱 프로젝트

## 프로젝트 개요

본 프로젝트는 사용자의 분위기, 이용 시간, 예산, 출발 시각을 바탕으로 안동 시내 여행 루트를 추천하는 발표용 앱 프로토타입입니다.

기존 아이디어는 AI 기반 위치기반 여행 루트 플랫폼이었지만, 실제 구현 가능성과 발표 일정에 맞추어 핵심 기능만 선별한 MVP 형태로 개발합니다.  
따라서 본 프로젝트의 목표는 완성형 상용 서비스가 아니라, 교수님 앞에서 추천 흐름과 지도 기반 경로 안내 과정을 시연할 수 있는 앱 프로토타입을 제작하는 것입니다.

## 프로젝트 목표

- 사용자가 원하는 여행 분위기와 조건을 입력한다.
- 조건에 맞는 안동 시내 장소를 추천한다.
- 추천된 장소들을 효율적인 방문 순서로 정렬한다.
- 모의지도 위에 추천 루트를 시각적으로 표시한다.
- 버스 시간표를 활용하여 경국대와 안동 시내 간 이동 흐름을 표현한다.
- 발표에서 Dijkstra, Greedy, LBS, 초개인화 큐레이션 개념을 설명할 수 있도록 구현한다.

## 핵심 아이디어

사용자는 여행 테마, 이용 시간, 예산, 출발 시각을 입력합니다.  
앱은 장소 데이터와 버스 시간표를 기반으로 조건에 맞는 장소를 필터링하고, Greedy 알고리즘으로 방문 순서를 결정합니다.  
장소와 장소 사이의 이동 경로는 모의지도 그래프에서 Dijkstra 알고리즘을 이용해 계산합니다.

실제 GPS, 실제 지도 API, 실시간 버스 정보, AI 학습 모델은 구현하지 않으며, 발표용 프로토타입에 맞게 정적 데이터와 모의지도 기반으로 기능을 구현합니다.

## 주요 기능

### 1. 조건 입력

사용자는 다음 조건을 입력합니다.

- 여행 분위기
  - 먹거리탐방
  - 조용한
  - 전통문화
  - 자연
- 총 이용 시간
- 예산
- 출발 시각

### 2. 장소 추천

장소 데이터에 포함된 태그, 예상 비용, 체류 시간, 영업 시간 등을 기준으로 조건에 맞는 장소를 필터링합니다.

예시:

- 사용자가 `먹거리탐방`을 선택하면 음식점, 시장, 카페를 우선 추천
- 사용자가 `조용한`을 선택하면 박물관, 북카페, 산책로 등을 우선 추천

### 3. 버스 시간표 적용

경국대에서 안동 시내로 이동하는 시작 구간과, 안동 시내에서 경국대로 돌아오는 복귀 구간에 버스 시간표를 적용합니다.

- 사용 노선: 110번, 210번
- 사용자가 입력한 출발 시각 이후 가장 가까운 버스 선택
- 실시간 지연, 결행, 교통 상황은 반영하지 않음

### 4. 여행 루트 생성

추천된 장소들을 기반으로 방문 순서를 생성합니다.

- Greedy 알고리즘: 현재 위치에서 가까우면서 조건 점수가 높은 장소를 우선 선택
- Dijkstra 알고리즘: 모의지도 그래프에서 장소 간 최단 경로 계산
- 총 소요 시간: 버스 대기 시간 + 버스 이동 시간 + 도보 이동 시간 + 장소 체류 시간

### 5. 모의지도 표시

실제 지도 API 대신 지도 배경 이미지 위에 장소와 경로를 표시합니다.

구현 요소:

- 장소 점 표시
- 장소 간 연결선 표시
- 추천 루트 강조
- 현재 위치 표시
- 방문 완료 표시
- 다음 장소 이동 버튼

### 6. 경로 재추천

사용자가 일부 장소를 방문한 후 경로 재추천 버튼을 누르면, 현재 위치와 남은 장소를 기준으로 다시 경로를 계산합니다.

## 사용 기술 개념

| 기술 | 프로젝트 내 역할 | 실제 구현 방식 |
|---|---|---|
| Dijkstra | 장소 간 최단 경로 계산 | 모의지도 그래프에서 가장 짧은 연결 경로 계산 |
| Greedy | 방문 순서 생성 | 현재 위치에서 조건 점수와 거리를 기준으로 다음 장소 선택 |
| LBS | 위치 기반 서비스 개념 표현 | 실제 GPS 대신 현재 위치 상태값으로 이동 시뮬레이션 |
| 초개인화 큐레이션 | 사용자 조건 반영 추천 | 분위기, 예산, 시간 태그 기반 룰기반 필터링 |
| 버스 시간표 | 경국대 ↔ 안동시내 이동 계산 | 정적 버스 시간표에서 가장 가까운 출발편 선택 |

## 구현 범위

### 반드시 구현할 기능

- Expo 앱 실행
- 시작 화면
- 조건 입력 화면
- 추천 결과 화면
- 모의지도 화면
- 장소 데이터 기반 분위기 필터링
- 추천 장소 목록 출력
- 모의지도에 장소 점과 경로선 표시
- 추천 루트 강조

### 가능하면 구현할 기능

- Greedy 방문 순서 생성
- Dijkstra 최단 경로 계산
- 버스 시간표 기반 출발편 선택
- 도보 이동 시간 계산
- 장소 체류 시간 계산
- 다음 장소로 이동 버튼

### 시간이 남으면 구현할 기능

- 경로 재추천
- 현재 위치 애니메이션
- 카테고리별 아이콘 고도화
- 카드 UI 개선
- 발표용 애니메이션 효과

## 제외 기능

본 프로젝트는 발표용 MVP이므로 다음 기능은 구현하지 않습니다.

- 실제 GPS 실시간 추적
- 실제 지도 API 연동
- 실시간 버스 지연 및 결행 반영
- 로그인 및 회원가입
- 서버 DB
- 실제 AI 학습 모델
- 실제 내비게이션 기능
